# Design System Usage

This project uses the **akshay-editorial** design system defined in design-system.md.

Before authoring or changing UI:

1. Read docs/design-system.md and use its tokens rather than inventing new colors, type scales, radii, or spacing.
2. Keep the visual hierarchy editorial and restrained: whitespace, rules, and alignment do the heavy lifting.
3. Use the component guidance for navigation, hero, section headers, project rows, experience rows, capability panels, and actions.
4. Preserve accessibility requirements and reduced-motion behavior.
5. If a new pattern is needed, add it to the design-system spec before using it in the interface.
